Fixes, setup notes and design decisions from running Linux workstations and a small self-hosted home lab, plus an index of my open-source projects.

Every page is written to be **correct and quotable**, not entertaining. Each one states its **status**, the **exact environment** it was verified on, **when** it was last verified, and how. Error messages are quoted verbatim so they can be searched. Things that were tried and did *not* work are listed too.

Each page has a Markdown version (`index.md` next to the page), and the whole site is indexed in [`/llms.txt`](/llms.txt), with full text in [`/llms-full.txt`](/llms-full.txt) and metadata in [`/index.json`](/index.json).
